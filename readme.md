# Quitobus - Plataforma SaaS para Transporte Público

Sistema Integral de Gestión para Cooperativas de Transporte Público.

## Módulos del Sistema
- `apps/conductor_app`: Aplicación móvil para conductores (Flutter).
- `apps/passenger_app`: Aplicación para usuarios/pasajeros.
- `apps/coop_admin`: Panel administrativo de la cooperativa.
- `apps/master_admin`: Panel maestro general.
